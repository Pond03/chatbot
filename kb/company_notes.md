# ข้อมูลบริษัทและโครงการที่เกี่ยวข้องกับ RAG

## บริษัท TRANSDEV.CO.TH
เป็นบริษัทในเครือของกลุ่ม TRANSCODE GROUP  
ดำเนินธุรกิจด้านการวิจัยและพัฒนาเทคโนโลยี AI สำหรับระบบจราจรอัจฉริยะ (Smart Traffic) และระบบขนส่งอัจฉริยะ (Smart Transport)

### วิสัยทัศน์
“พัฒนาโครงสร้างพื้นฐานอัจฉริยะด้วยเทคโนโลยี AI และการจัดการข้อมูลแบบเรียลไทม์”

---

## โครงการ AI Workspace
AI Workspace คือโครงการต้นแบบที่ออกแบบโดย วรรณวรินทร์ รักญาติ  
เพื่อพัฒนา **ระบบแชตบอตที่เชื่อมต่อกับฐานความรู้ (Knowledge Base)** โดยใช้แนวคิด **Retrieval-Augmented Generation (RAG)**  

### จุดประสงค์ของโครงการ
- ทดสอบการทำงานของ RAG ในระดับ Local Environment  
- ทดลองเชื่อมต่อ LM Studio กับฐานข้อมูลภายในโฟลเดอร์ kb  
- ปรับแต่งระบบค้นหาด้วย TF-IDF และ cosine similarity  
- ใช้ Node.js ทำหน้าที่จัดการ API และ context ก่อนส่งให้โมเดล  

### โครงสร้างของระบบ
1. **Frontend (AI Workspace UI)**  
   - อินเทอร์เฟซแชตแบบ Light/Dark Mode  
   - ฟังก์ชันต่อเนื่อง (Conversation Memory)  
   - ปุ่ม “New Chat” สำหรับเริ่มบทสนทนาใหม่  

2. **Backend (RAG Server)**  
   - ดึงข้อมูลจากโฟลเดอร์ `kb`  
   - แบ่งข้อความเป็นชิ้น (Chunk) เพื่อค้นหาเร็วขึ้น  
   - ส่ง context ที่เกี่ยวข้องไปยังโมเดล  

3. **Model Layer**  
   - ใช้ LM Studio เป็น Local Model Server  
   - โมเดลตัวอย่าง: `phi-3.5-mini-instruct`, `llama-3.2-1b-instruct`, `typhoon2.5-qwen3-4b-i1`

---

## การประยุกต์ใช้ RAG ภายในองค์กร
- ใช้ตอบคำถามด้านเทคนิคภายใน (Internal FAQ)  
- สร้างระบบแนะนำ (Knowledge Assistant) สำหรับวิศวกร  
- จัดการเอกสารบริษัท เช่น รายงาน, คู่มือ, ข้อมูลเทคนิค  
- ใช้ตรวจสอบความถูกต้องของข้อมูล AI ก่อนเผยแพร่
